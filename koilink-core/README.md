# Koilink 内容过滤（WordPress 插件）

为 Koilink 社交平台（WordPress + BuddyPress，部署于 Zeabur）提供违禁词自动过滤。

## 功能

- 过滤范围：BuddyPress 动态、WordPress 文章（标题/正文）、评论
- 命中处理：自动替换为全角「＊」后正常发布
- 词库来源（三者合并）：
  1. 远程词库：服务器每日自动从「设置 → 内容过滤」里配置的地址拉取，默认使用 DangerousSpamWords 中文词条，也可换成任意「每行一词」的纯文本地址
  2. 本地文件：插件目录下的 `words.txt`（可选，不存在则忽略）
  3. 自定义词条：设置页文本框，随时加词
- `#` 开头的行、空行自动忽略

## 安装

1. WordPress 后台 → 插件 → 安装插件 → 上传插件 → 选择 `koilink-core.zip` → 启用
2. 设置 → 内容过滤 → 点「立即更新词库」，提示更新成功即可

## 开发

- 版本：0.1.0
- 结构：单文件插件 `koilink-core.php`，无构建步骤
- 卸载：停用即清除定时任务；词库缓存存于 options 表
